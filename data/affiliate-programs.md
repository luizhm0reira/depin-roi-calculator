## Per-vendor details

### 1. HeliumDeploy — Creator Program ✅
- **Program page:** https://heliumdeploy.com/pages/become-an-affiliate (opened 2026-10-02, live)
- **Signup:** form on the program page → UpPromote portal at affiliates.heliumdeploy.com (direct register page indexed: `affiliates.heliumdeploy.com/heliumdeploy/register` — **unverified by direct open**)
- **Commission:** Tier 1 "Creator" = **5% of the whole order total**; Tier 2 "Partner" (manual promotion for top sellers) = **8%**. Page-verified examples at 5%: BitFortune BS-1 $229 → $11.45; NerdQX $299.99 → $15.00; Magic Miner 40T $649 → $32.45; GekkoScience KBOX $800 → $40.00; Harlo B30 $899 → $44.95 (8% tier → $71.92). Fits the prior "$11–72/sale" range.
- **Cookie:** **unverified** — the current page relies on referral link *plus* personal discount code (code credits even if cookies cleared or buyer returns later). An older cached page stated a 30-day cookie; do not rely on it.
- **Payout:** PayPal, once a month, **no minimum threshold**. Instant approval at signup — no follower minimum, no review queue, open worldwide, no exclusivity (comparison videos vs competitors explicitly allowed). Paid ads allowed except bidding on their own Google keywords.
- **Coverage (verified product pages):** ROVR TarantulaX Bundle (https://heliumdeploy.com/products/rovr-tarantulax-bundle); GEODNET/HYFIX MobileCM triple-band $695 (https://heliumdeploy.com/products/geodnet-mobilecm-triple-band — **sold out at time of check**); Wingbits WB200 $495 and MGW310 $1,095 (both **sold out at time of check**); WeatherXM WS2000 $400 (availability mixed); Nubila collection (https://heliumdeploy.com/collections/nubila); Karrier One HOTSPOT1 (sold via HeliumDeploy per third-party listing — exact page **unverified**, but program pays on whole order total regardless).
- **Caveats:** catalogue has pivoted toward Bitcoin ASICs; **no Helium hotspots** currently listed. Sold-out SKUs convert poorly — check inventory before featuring.

### 2. RAKwireless — Affiliate Program ✅
- **Program page:** https://www.rakwireless.com/en-us/company/affiliate-program
- **Terms:** https://www.rakwireless.com/en-us/legal/affiliate-program-terms (last updated May 20, 2025)
- **Commission:** flat **5%** of total sale (excl. shipping/duties/taxes), paid via Goaffpro → PayPal on the 1st and 15th of each month, after a 30-day review period. **$20 minimum payout**.
- **Cookie:** **180 days** (stated in both program page and terms).
- **Requirements:** 18+, personal PayPal account; signup via Goaffpro (exact portal URL **unverified** — terms say sign up "through RAKwireless"). **PPC bidding NOT allowed** (suspension risk). No self-purchases via own links. Affiliates may use RAK logo/product images/specs without prior authorization. No stated audience/traffic minimum.
- **Coverage:** purchases on **store.rakwireless.com** — includes RAK hotspots sold through the official store. **Exclusion in terms: "sales outside the Store, including the RAK HotSpot Miner via the CalChip website, are excluded."** RAK's own stats note affiliates generated $3M+ "excluding hotspots" — consistent with the CalChip exclusion.
- **Status:** active, fully verified.

### 4. Seeed Studio — Creator & Affiliate Program ✅
- **Signup:** https://www.seeedstudio.com/blog/affiliate-program/ ("Join Affiliate Program"; requires a Seeed site account) — ✅ APPROVED 2026-10-05, code zDAXnT9, link param `sensecap_affiliate=zDAXnT9` (generate per-product links via Promo Data → Referral Link form)

- **Requirements:** free; "Anyone" can join (large e-commerce site or small blog). No PPC bidding on affiliate links (account closed, commissions forfeited); no commissions on self-purchases.
- **Coverage:** all eligible products on seeedstudio.com, including **SenseCAP M1/M2** (Seeed's own products). Campaigns updated through 2026.
- **Sources:** https://www.seeedstudio.com/blog/affiliate-program/ · https://www.seeedstudio.com/amasty-affiliate-faq · https://www.seeedstudio.com/amasty-affiliate-conditions (eff. Nov 29, 2024)

### 6. Nubila — Marco Referral Program ✅ (points-based, NOT cash)
- **How it works:** in-app only (Nubila app → Account → Invite Friends). No web signup; referral codes issued inside the app (a Marco-owning account appears required in practice).
- **Reward:** **28,000 NUBI Points** per successful referral (friend buys a Marco with your code + activates + runs 3 consecutive days of data); the friend gets a **$50 discount coupon**. Super Ambassador: 100 successful referrals → 100,000 NUBI bonus; referring another Super Ambassador → 500,000 NUBI.
- **Payout:** NUBI Points (2B points allocated) — **no cash payout**. Code-based, no cookie.
- **Status:** active (announced June 6, 2025; no closure announced).
- **Cash route:** use the HeliumDeploy Creator Program link for Marco sales instead.
- **Source:** https://medium.com/@nubilanetwork/introducing-marco-referral-program-cb4a2dbe4b6b (official Nubila Network post)

### 7. DIMO — Referral Program (DIP-7) ✅ (token-based, NOT cash)
- **Reward:** **50 $DIMO to BOTH referrer and referee**, one-time, when the new user connects a vehicle; referral code/link must be entered **before** connecting the first vehicle. Pool capped (2.5M $DIMO / first 25,000 referrals, amendable by governance).
- **Payout:** tokens to the DIMO account, not cash; no cookie/threshold; anyone can generate a referral code in the DIMO Mobile app (no connected car required). Rewards app onboarding/vehicle connection, **not device purchases**.
- **Signup:** in the DIMO Mobile app (points/referrals tab); public entry: https://dimo.zone/
- **Cash route:** DIMO hardware is on Amazon (e.g. "DIMO GPS Vehicle Tracker with Real-Time Location", amazon.com/dp/B0F14R132S) — Amazon Associates commission at the Electronics category rate (**current rate unverified**; typically 4%).
- **Sources:** https://docs.dimo.foundation/governance/improvement-proposals/dip7 · https://github.com/dimo-network/dip/blob/HEAD/improvement-proposals/dip7.md
